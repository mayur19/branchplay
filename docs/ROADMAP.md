# Delivery roadmap

1. **Foundation:** project setup, graph types, validation, deterministic runtime and initial schema.
2. **Authoring:** accounts, projects, visual editor, variables, assets and preview.
3. **Review and release:** collaborator roles, snapshot comments, validation gates and immutable publication.
4. **Player:** public playback, save/resume, endings, accessibility and safe response shapes.
5. **Insights and readiness:** aggregate paths, export/import, moderation, performance, deployment and browser coverage.
